Canon is the shared memory of a company, for its people and its AI agents. It keeps one record of decisions, each backed by a quote checked word for word against its source, knows who has the authority to change a rule, and flags drift: a message that breaks a decision, an out-of-date wiki page, an agent about to act against the record. Agent-native: Canon is an MCP server, so Claude Code or Codex call check_intent first and get blocked from a Friday deploy, with the incident that banned it. Live demo: post in our public Discord and Canon replies within a minute. Gemini 3.5 Flash-Lite on Vertex AI extracts, reconciles and judges with structured output, reads PDFs and screenshots, and refuses when the record has no answer. Firestore stores the record and runs vector search per workspace. Cloud Run hosts the API, MCP and an ADK agent over A2A; Firebase Hosting serves the web app. Benchmark: 82/82 decisions found, 5/5 unanswerable refused.

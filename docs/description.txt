Canon is the shared memory of a company, for its people and its AI agents. It keeps one record of decisions, each backed by a quote checked word for word against its source, and flags drift: a new message that contradicts a decision, a stale wiki page, a broken premise. Agent-native: Canon is an MCP server, so Claude Code or Codex call check_intent before acting. Ask a coding agent for a Friday cron deploy and Canon blocks it, citing the incident review. Gemini 3.5 Flash-Lite on Vertex AI extracts decisions, reconciles them and answers with structured output; it refuses when the record has no answer. gemini-embedding-001 embeds chunks and decisions. Firestore (database canon) stores the record and runs vector search with a per-workspace prefilter. Cloud Run hosts the API, MCP server and an ADK agent over A2A, scaling to zero. Firebase Hosting serves the React app. On a labelled synthetic gold set: 37/38 decisions found, 5/5 unanswerable refused, p50 1.1 s.
